# 企业微信智能机器人：群内查股（本机长连接）

普通的企业微信「群机器人 Webhook」只负责发送日报，不能接收群消息。要在群里输入股票代码并获得回复，需要另建一个「智能机器人」，选择 **API 模式 → 使用长连接**。它由你的常开电脑主动连到企业微信，不需要公网域名、端口或 WebUI。

> 本接入使用 `wecom-aibot-sdk==1.0.8`。它是社区维护的 Python 封装，不是企业微信官方 Python SDK；上线前请自行确认其版本与许可证。项目默认关闭此功能。

## 创建与配置

1. 在企业微信管理端创建「智能机器人」，选择 API 模式和「使用长连接」。
2. 把该机器人加入「红红火火」群。保留现有群 Webhook，它继续用来发送盘后海报。
3. 只在常开电脑的 `.env` 中填写以下项，**不要写进 GitHub Secrets、代码或聊天**：

```dotenv
WECOM_AIBOT_ENABLED=true
WECOM_AIBOT_ID=机器人ID
WECOM_AIBOT_SECRET=机器人Secret
BOT_ADMIN_USERS=你的企业微信user_id
# 可选：确认群 ID 后锁定到该群
# WECOM_AIBOT_ALLOWED_CHAT_IDS=红红火火对应的chat_id
```

首次启动时，`BOT_ADMIN_USERS` 还未设置，机器人会拒绝所有命令并在本机日志记录发信人的 `user_id`。复制自己的 ID 到 `.env` 后重启即可；未列入该变量的群成员不能触发数据查询或模型调用。

## 群内用法

群里建议先 @机器人再发送指令：

- `600519` 或 `查 600519`：快速行情，不调用模型。
- `分析 600519`：提交完整研究任务，才会调用已配置的模型。
- `贵州茅台最近怎么看？`、`这次业绩有什么影响？`：轻量自由问答。机器人先读取可用行情、A 股公告和最近报告，再调用一次模型；不需要开启完整 Agent。
- `自选`：查看常用股。常用股会进入盘后日报和重要事件提醒。
- `自选 add 600519`：请求加入常用股；机器人不会立即修改。
- `自选 confirm 600519`：确认加入。
- `自选 remove 600519`：移出常用股。

任何符合格式的 A 股、港股或美股代码都可临时查询；只有你确认加入的常用股才会增加日报和提醒范围。常用股更改保存到本机 `.env` 的 `STOCK_LIST`，因此应由本机定时任务作为正式日报来源。

轻量自由问答同样不受三只初始自选股限制。新股票可以用代码或可识别的名称临时询问，机器人不会自动把它加入自选；只有执行 `自选 add` 并再次 `confirm` 才会扩大自动日报或提醒范围。该模式不是完整 Agent：不做自主工具编排、多模型回退或自动交易，只进行一次有字数和超时上限的问答调用。

## 盘中重要提醒

常开电脑可选开启低噪音监控：

```dotenv
WECOM_WATCHLIST_MONITOR_ENABLED=true
WECOM_WATCHLIST_MONITOR_INTERVAL_MINUTES=5
WECOM_WATCHLIST_MOVE_ALERT_PCT=5.0
WECOM_AIBOT_ALLOWED_CHAT_IDS=目标群chat_id
```

当前自动提醒范围只读取 `STOCK_LIST` 中的 A 股，包括重大/业绩公告、日内涨跌幅达到阈值，以及 MA20、近20日高低点的跨越。第一次启动只建立公告和技术位基线，不补发旧消息；同一事件会去重。普通新闻不触发，判断规则不调用模型。盘后完整海报及大盘复盘仍由 GitHub Actions 每个工作日执行一次。

临时问答支持更多新股，但不会自动扩大上述监控范围。需要监控时仍要通过 `自选 add` 和 `自选 confirm` 明确加入。

## 启动与边界

安装依赖后，在常开电脑上只启动对话机器人：

```bash
pip install -r requirements.txt
python scripts/run_wecom_aibot.py
```

这个启动方式不会执行日报任务，也不会打开任何公网端口；因此可以继续由 GitHub Actions 作为唯一的日报和群 Webhook 推送来源。开启盘中监控后，本机只发送上述去重提醒，不会重复生成盘后日报。关闭终端或重启电脑后，机器人和盘中提醒都会停止；稳定一周后再配置系统登录后自启动。
